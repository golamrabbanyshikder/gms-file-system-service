\# 📁 GMS File System Service



Java 21 / Spring Boot 3.3 microservice for secure medical file storage.



\## 🚀 Run locally

\\`\\`\\`bash

mvn spring-boot:run

\# Starts on http://localhost:8081

\\`\\`\\`



\## 🔐 Auth

All endpoints require JWT. Get a token from `backend-service`.



Part of the \[Global Medical System](https://github.com/golamrabbanyshikder/global-medical-system) project.
